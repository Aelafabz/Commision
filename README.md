# Commission App

This project now uses a PHP backend with a static HTML/CSS/JS frontend.

## Run locally

From the project root, start the PHP server:

```bash
php -S 127.0.0.1:8000 -t server
```

Then open:

```text
http://127.0.0.1:8000/
```

The frontend assets live in the Frontend folder and the API endpoints are served by server/index.php.
